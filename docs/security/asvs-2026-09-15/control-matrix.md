# ASVS 5.0.0 Level 2 control matrix

All **253 cumulative L1/L2 requirements** are dispositioned below; 92 L3-only requirements are excluded. This is a complete catalog disposition, not a claim that every control was dynamically tested.

**Statuses:** PASS = supported within the stated scope/method; FAIL = a counterexample or identified control absence; PARTIAL = some elements supported but full requirement not demonstrated; NOT TESTED = insufficient evidence; NOT APPLICABLE = absent first-party technology/feature with rationale. No unverified control is counted as a pass.

A source-only result describes the inspected working tree, not proof of the production deployment revision. See [report](report.md) for scope, finding details and evidence index.

Standard text: [OWASP ASVS v5.0.0 catalog](https://github.com/OWASP/ASVS/blob/v5.0.0/5.0/docs_en/OWASP_Application_Security_Verification_Standard_5.0.0_en.flat.json), licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
